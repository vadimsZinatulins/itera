# How can commute practice minimise typing without doing the reasoning for the learner?

Labels: wayfinder:prototype
Type: prototype
Status: open
Blocked by: 01

## Question

Using the prototype from [Which main workflow makes a ten-minute practice session feel natural?](01-compare-main-workflows.md) as context, which typing aids make a short practice conversation comfortable on mobile without reducing it to canned answers or revealing the reasoning prematurely?

Compare concrete interactions with the user. Typing must remain available; voice is not part of this commute experience. Explore concise prompts, optional response scaffolding or follow-up actions, Hint, Explain it, and Finish here. Identify which aids feel useful and which interfere with thinking. Do not assume all suggested aids belong in the final design.

Use simulated conversations and in-memory state. Resolution requires live user reaction, not an agent’s judgment of usability.
